📖 사용 방법

1. 학생 등록 — [학생 등록] 탭에서 명단 입력 → 자동 적용됨
2. 책상 설정 — [배치 설정] 탭에서 분단 수, 총수, 유형 설정
3. 배치 실행 — 상단 메뉴의 [✨ 자리 배치 실행] 클릭

자리 직접 변경 및 고정(자물쇠)
• 빈 자리 클릭 → 공석(✕) 지정/해제
• 학생 클릭 후 다른 자리 클릭 → 두 자리 학생 교체
• 같은 자리 두 번 클릭 → 자물쇠(고정) ON/OFF
    ※ 잠긴 자리는 재배치 시에도 해당 학생이 그대로 유지됩니다!

🖨️ 출력 및 저장
• 출력 — 현재 화면 상태를 그대로 인쇄합니다 (크기 자동 축소 지원)
• 엑셀/이미지 저장 — 깔끔한 엑셀 파일이나 그림 파일로 저장
• 교사 시점 — 교사 시점으로 좌우 상하 반전 보기
